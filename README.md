# TeloVis Pro — Landing Page

Página de vendas do **TeloVis Pro**, sistema de gestão para salões de beleza, barbearias e clínicas de
estética. Um produto TeloVis Tech (CNPJ 51.960.551/0001-38).

**Produção:** https://telovispro.com, publicada pela Lovable
(projeto `0b8ffaca-8f5b-4b8d-a353-2aea2557060c`, repositório `telovis-pro-canvas`).

O projeto é o template TanStack Start da Lovable, com a LP em HTML + CSS + JS vanilla dentro de
`src/landing/` (PT/EN/ES, segmentos, módulos, simulador por profissional e formulário → WhatsApp).
Nenhum dado é salvo: todo CTA abre o WhatsApp (11) 95407-9335.

```sh
npm install
npm run dev
npm run build && npm test
```

- Onde mexer em cada coisa e como publicar: `DEPLOY.md`
- Artes de divulgação (prospecção e status do WhatsApp): `divulgacao/` (fora do git)
- Arquitetura e decisões: `TeloVis Workspace/Telovis-hq/arquitetura-telovis-barber-landing/`

Commits enviados para `main` sincronizam com o editor da Lovable. Não reescreva histórico já enviado.
